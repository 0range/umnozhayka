# Умножайка

Небольшая адаптивная веб-игра для тренировки таблицы умножения. Сделана для
Сони, 8 лет: без регистрации, рекламы и лишних экранов.

**Играть:** https://umnozhayka.vitali-arz.chatgpt.site

## Что умеет

- умная тренировка на 12 примеров с выбором готового ответа;
- тренировка на 12 примеров с самостоятельным вводом ответа;
- большая проверка на 20 случайных примеров только с цифровой клавиатурой;
- повторение ошибочных примеров через несколько вопросов;
- экранная цифровая клавиатура, `Enter` для проверки и `Backspace` для удаления;
- четыре варианта ответа и управление клавишами `1`–`4` в режиме выбора;
- карта знаний таблицы от 2 до 9;
- точность, среднее время ответа, серии и список слабых мест;
- адаптивный интерфейс для телефона, планшета и компьютера;
- сохранение прогресса в `localStorage` текущего браузера.

Приложение считает `a × b` и `b × a` одним навыком. При выборе следующего
вопроса новые и плохо усвоенные примеры получают больший вес. Для уровня
освоения учитываются точность, количество попыток, скорость и серия правильных
ответов.

## Локальный запуск

Нужен Node.js `>=22.13.0`.

```bash
npm ci
npm run dev
```

Production-проверка:

```bash
npm run build
npm run validate:artifact
```

## Деплой

Текущая рабочая версия публикуется через ChatGPT Sites. Для переноса на
Timeweb Cloud можно подключить этот репозиторий в App Platform как Frontend →
Next.js с включённым SSR:

- build command: `npm run build:timeweb`;
- start command: `npm run start:timeweb`;
- Node.js: `24` (или `22.13+`);
- переменные окружения не требуются.

## Данные

Сейчас вся статистика хранится только на устройстве игрока. Это делает первую
версию простой и приватной, но прогресс не синхронизируется между браузерами.
Следующая возможная итерация — отдельный родительский профиль и синхронизация
результатов между устройствами.
